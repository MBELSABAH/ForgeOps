# User guide

1. Open Overview to inspect workload, priorities and overdue orders. Click a metric or priority to open a filtered queue.
2. Choose New work order. Enter a specific title, equipment, facility, description, priority and due date. Assign a technician now or leave it unassigned.
3. Open an order and choose Edit work order to update information or assign a roster technician.
4. In Move work forward, select In progress and choose Save status. The browser calls the status API and updates the badge and history.
5. To resolve, choose Resolved and explain the repair plus verification in Resolution notes. Saving without notes is rejected. Return to Overview to see the updated metrics.
6. Reopen by selecting Open or In progress. Current notes clear; the previous resolution remains in Activity history.
7. Archive duplicate/inactive work to remove it from the operational queue without losing its record. Find it in Archived and restore it before editing.

Due today means the entire Halifax calendar day. Only earlier unresolved, unarchived deadlines are overdue. On narrow screens use the navigation menu and scroll the table horizontally to see all columns.
